## 4. Proof độc lập và termination

- **P1 — ID/slot:** giả sử nextId còn biểu diễn chính xác và chưa dùng. ID mới khác mọi ID cũ; increment giữ tính không cấp lại. Với V slots phân biệt, ít nhất một số0..V còn trống; vòng while của nextFreeSlot tăng slot nên dừng trong ≤V lần tăng, trả minimum. Clone rồi thêm đúng một vertex không đổi slot cũ. Không mở rộng proof qua ID precision exhaustion. [src/structures/graph.js:83–98](https://github.com/Nggvanchi/AlgoVision/blob/ee26d09eb442c00a5eb31ba14acf5caef2d2b04e/src/structures/graph.js#L83-L98)
- **P2 — adjacency:** insertion tìm vị trí slot lớn hơn đầu tiên nên bảo toàn thứ tự; reject duplicate/self-loop/missing trước chèn. Với undirected, thao tác cả hai phía giữ đối xứng; deletion filter không đổi thứ tự phần tử còn lại. RemoveVertex bỏ owner list và lọc id khỏi mọi list còn lại nên không dangling references. Loops for/map/filter hữu hạn trên valid graph. [src/structures/graph.js:101–147](https://github.com/Nggvanchi/AlgoVision/blob/ee26d09eb442c00a5eb31ba14acf5caef2d2b04e/src/structures/graph.js#L101-L147)
- **P3 — copy:** cloneGraph dựng vertices dictionary mới, từng vertex object mới, adjacency dictionary mới và từng array mới. Edit chỉ ghi vào clone; reject/miss vẫn clone vì clone trước nhánh kiểm tra. Query snapshots gọi cloneGraph mỗi lần; BFS/DFS copy maps/arrays và neighbors copy output prefix. Vì vậy sửa graph/owned state của một step không đổi input/old steps; không suy mọi API đều defensive freeze hoặc listVertices deep-copy.
