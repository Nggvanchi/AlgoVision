# AlgoVision

AlgoVision là dự án trực quan hóa thuật toán và cấu trúc dữ liệu, được xây dựng nhằm giúp người học hiểu cách các thuật toán hoạt động thông qua từng bước xử lý.

## Mục tiêu

- Trực quan hóa quá trình thực thi thuật toán.
- Theo dõi sự thay đổi của dữ liệu qua từng bước.
- So sánh hiệu quả của các thuật toán dựa trên số lần so sánh.
- Hỗ trợ việc học cấu trúc dữ liệu và giải thuật.

## Công nghệ sử dụng

- HTML
- CSS
- JavaScript
- Vite
- Git và GitHub

## Chức năng

### Sắp xếp

- Bubble Sort
- Selection Sort
- Insertion Sort

### Tìm kiếm

- Linear Search
- Binary Search
- So sánh thuật toán tìm kiếm (đang phát triển)

### Cấu trúc dữ liệu

Các chức năng sẽ được bổ sung trong những phiên bản tiếp theo.

## Cài đặt và chạy dự án

**Yêu cầu:** Node.js và pnpm.

```bash
git clone https://github.com/Nggvanchi/AlgoVision.git
cd AlgoVision
pnpm install
pnpm dev
```

## Trạng thái phát triển

Dự án đang trong giai đoạn phát triển. Các chức năng sẽ được hoàn thiện và kiểm thử theo từng cột mốc.
